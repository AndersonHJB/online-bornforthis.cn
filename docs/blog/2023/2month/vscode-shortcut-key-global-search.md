VsCode 其实有强大的快捷键搜索功能，全部快捷键可以参考官网：[Visual Studio Code Key Bindings](https://code.visualstudio.com/docs/getstarted/keybindings)

Mac 快捷键：[keyboard-shortcuts-macos.pdf](/pdf/keyboard-shortcuts-macos.pdf)

## 1. VsCode 全局搜索 (可搜代码，文件等)

### Windows:

`Ctrl+Shift+F`

### Mac:

`Cmd+Shift+F`

## 2. 搜索文件名 (可以实现跳转到某一行)

### Windows:

`Ctrl+T`

### Mac:

`Cmd+T`

## 3. 打开或关闭 panel

`Cmd+J`

## VScode 如何修改全局搜索快捷键?

依次点击“**文件-首选项-键盘快捷方式**”即可查询和修改快捷键，或者使用快捷键，**先按 ctrl+K，然后再按 ctrl + S**。

![](./vscode-shortcut-key-global-search.assets/image-20230222000719503.png)

输入“search”，带一个就是全局搜索快捷键的默认设置，双击即可，进行修改。

![](./vscode-shortcut-key-global-search.assets/image-20230222000707575.png)
