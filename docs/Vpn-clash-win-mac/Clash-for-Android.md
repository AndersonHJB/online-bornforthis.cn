Clash For Android 是一款新推出的 V2ray 客户端。自带服务器测速，可用性测试等功能，用户不需要关心那个节点速度快慢，可用与否，十分适合新手用户。 [点此直接下载Clash For Android](https://github.com/Kr328/ClashForAndroid/releases/download/v2.5.11/cfa-2.5.11-foss-arm64-v8a-release.apk) 如果在手机上无法下载 Clash，可以在电脑下载好，然后利用微信或者 QQ 传输到手机上，保存为手机上的文件，再利用手机的文件或者资源管理器。

## 1. 复制你专属的订阅链接

### 1.1 打开订阅网站

[https://mf.bornforthis.cn/content](https://mf.bornforthis.cn/content)

需要密码，但凡购买的，都会给你开通专属有效期内的密码。

### 1.2 复制你的专属订阅链接

![](./Clash-for-Android.assets/image-20230611150116625.png)

进入之后。

### 1.3 选择复制安卓手机的订阅

![](./Clash-for-Android.assets/image-20230611190811177.png)

## 2. 手机配置

### 2.1 手机上打开clash, 选择配置

![](./Clash-for-Android.assets/s1.png)

### 2.2 选择 +新配置

![](./Clash-for-Android.assets/s3.png)

### 2.3 选择从 URL 导入

![](./Clash-for-Android.assets/s4.png)

### 2.4 填写配置

按照下图备注填写， URL 就是之前从 [https://mf.bornforthis.cn/content](https://mf.bornforthis.cn/content) 上复制的 Clash 订阅码链接地址。 此链接地址你也可以通过微信、QQ 等发送到手机上，然后复制。

![](./Clash-for-Android.assets/s5_fix.png)

### 2.5 选中 IGG ， 然后返回

![](./Clash-for-Android.assets/s6.png)

## 3. 打开代理

### 3.1 按下图点击 已停止 按钮开启 VPN 连接

![](./Clash-for-Android.assets/s7.png)

按下图显示 运行中 ， 就代表连接成功。

![](./Clash-for-Android.assets/s8.png)
