## 1. 方法一：手机端试用

没有别的方法，只能选择手机使用：Gemini，用几天后再次尝试给网页版。

当然，有网友说给你谷歌 help 发邮件，过几天就会好。也可以考虑试一试，不知道具体结果怎么样。



## 2. 方法二：邀请新入制
