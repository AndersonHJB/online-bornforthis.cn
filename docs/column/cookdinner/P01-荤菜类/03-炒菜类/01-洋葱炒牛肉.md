### 1. 健康功效

- 牛肉:补脾胃、强筋骨、益气血
- 洋葱: 解毒
- 姜: 降逆止呕、化痰止咳、散寒解表

### 4. 小贴士

牛肉事先腌制一下，不但会使牛肉去腥入味，还会使牛肉变得很嫩。

@tab:active 范大厨版

## 1. 食材

| 牛柳       | 花椒     | 生抽     | 盐   | 白胡椒粉 | 蛋清 | 玉米淀粉 | 洋葱 | 青红尖椒 |
| ---------- | -------- | -------- | ---- | -------- | ---- | -------- | ---- | -------- |
| **小米椒** | **蒜片** | **姜片** |      |          |      |          |      |          |

## 2. 步骤

1. 准备花椒水；（花椒泡水）去腥增香；
2. 洋葱：切丝、切块都可以；
3. 青尖椒：切小段；
4. 切牛肉：横切牛羊，顺切猪——>切小块——>清水清洗一下切好的牛肉——>挤干水分；
5. 对挤干的牛肉，加入适量的花椒水——>抓匀牛肉，使牛肉吃饱水；（多次加水，多次抓匀到没水为止。感觉牛肉湿漉漉的状态就可以了）
6. 加入：适量的生抽——>抓匀；
7. 加入：（少）盐、（少）白胡椒粉——>抓匀；（抓到滑滑的）
8. 加入：一个蛋清——>抓匀；
9. 加入：玉米淀粉——>抓匀；
10. 加入：适量的油，封油；
11. 中小火——>锅中加油，热锅温油就可以——>加入牛肉，先不动等待定型，慢慢的搅开——>等肉没有红色即可出锅；
12. 油热——>加入：姜片、蒜片、小米辣——>炒出香味——>加入青尖椒——>翻炒到青尖椒起虎皮——>加入：洋葱——>加入一点：盐；
13. 加入牛肉——>翻炒均匀——>加入：20ml 生抽、10ml 老抽、2 克糖，翻炒均匀；
14. 加入：白胡椒粉（去腥增香）
