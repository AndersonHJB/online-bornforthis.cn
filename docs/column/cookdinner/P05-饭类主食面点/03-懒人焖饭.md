## 1. 食材

| 大米 | 胡萝卜 | 土豆 | 香菇 | 腊肠 or 午餐肉 | 洋葱 | 豌豆（青豆） | 玉米粒 |
| ---- | ------ | ---- | ---- | -------------- | ---- | ------------ | ------ |

> 有啥菜就加啥菜

## 2. 步骤

1. 洗好大米；

2. 胡萝卜、土豆、香菇、腊肉、洋葱：切丁；

3. 把腊肠放入米中；

    ::: details

    ![](./03-懒人焖饭.assets/image-20250511135315534.png)

    :::

4. 加盐、生抽、老抽（上色）、蚝油——>抓匀；

5. 土豆、洋葱——>加盐（3g）、糖（2g）、黑胡椒（2 拧）、香油——>拌匀；

    ::: details

    ![](./03-懒人焖饭.assets/image-20250511140313401.png)

    :::

6. 放入电饭锅：

    1. 油拌过的土豆、洋葱，铺在电饭锅的底部；

    2. 接着下入米饭（包含腊肉）

    3. 最后放入配菜：胡萝卜、土豆、香菇、玉米粒、腊肉、豌豆（青豆）

        ::: details

        ![](./03-懒人焖饭.assets/image-20250511140824148.png)

        :::

7. 加入水，和米是 1:1
