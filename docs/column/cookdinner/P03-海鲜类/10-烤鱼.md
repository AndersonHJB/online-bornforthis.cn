| **辣椒面** | **2 瓶啤酒** | **莴笋**   |          |            |            |



## 2. 步骤

1. 鱼从背部打开，鱼改刀不要切开两边，开中间就行；

    ::: details

    <img src="./10-烤鱼.assets/image-20250919202528006.png" style="zoom:25%;" />

    :::

2. 腌制鱼：胡椒、盐简单腌制即可（鱼新鲜现杀）

3. 鱼表面抹点生粉；

    ::: details

    <img src="./10-烤鱼.assets/image-20250919203124549.png" style="zoom:25%;" />

    :::

4. 切：土豆片、洋葱切块、莲藕切片、小香葱碎、小米辣、黄瓜、木耳；

5. 处理素菜：锅中加油，把不好熟的土豆、莲藕的炒一下，炒一会之后加入：黄瓜、木耳，翻炒一下——>加入少量的水——>加入一些：白胡椒、一些盐、鸡粉——>炒完之后导入烤盘中；

6. 煎炸鱼：锅中少量油——>火：调整到中火——>鱼的背部先煎一下；

    ::: details

    <img src="./10-烤鱼.assets/image-20250919204039862.png" style="zoom:25%;" />

    :::

7. 不要动这条鱼，看中间焦化差不多了，可以动整个锅把鱼的每个部位煎制；（小火慢煎 2 分钟）

8. 然后翻面，想翻鱼不要坏，最好煎到鱼那面是金黄色的；

    ::: details

    <img src="./10-烤鱼.assets/image-20250919204300756.png" style="zoom:25%;" />

    :::

    > 其实鱼是不会粘锅的，粘锅是因为油温下降，鱼出水了。导致鱼皮粘在上面；

9. 把煎好的鱼，放入烤盘上面；

10. 烤鱼料：锅热加入菜籽油——>下入：蒜片、小米辣、豆瓣酱、辣椒面、火锅底料、2 瓶啤酒（8+1）；

11. 烤盘上摆上喜欢的配料：

     ::: details

     <img src="./10-烤鱼.assets/image-20250919204921959.png" style="zoom:25%;" />

     :::

12. 淋上烤鱼酱，然后铺上蒜末、葱花；

13. 锅中加油、干辣椒段，烧热——>淋上去；

@tab 2. 范大厨

## 1. 食材

| ---------- | -------- | ---------- | -------- | ---------- | ---------- | ------ | ------ |

## 2. 步骤

1. 提前泡好：葱姜水；

2. 把鱼的尾 qi 剪掉，把鱼的肚子完全破开：

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222124272.png" style="zoom:25%;" />

    :::

3. 顺着脊椎骨的一侧下刀：

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222159403.png" style="zoom:25%;" />

    :::

4. 另外一侧也是，接着拿剪刀从头往后把脊椎骨剪剪，拿出鱼的脊椎骨；

5. 改花刀：

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222324723.png" style="zoom:25%;" />

    :::

6. 腌制鱼：往葱姜水中加入：1 勺盐，搅匀并淋到鱼上：

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222506626.png" style="zoom:25%;" />

    :::

7. 腌制 30 分钟；

8. 在鱼皮表面撒上一层干粉淀粉：

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222604938.png" style="zoom:25%;" />

    :::

9. 准备配料：大葱片、姜片、玉米、莲藕片、土豆片、西兰花、芹菜等，按自己喜欢安排；

10. 锅热加油，撒点盐（防止鱼破皮）；

    ::: details

    <img src="./10-烤鱼.assets/image-20250919222755290.png" style="zoom:25%;" />

    :::

11. 下锅之后先别动鱼，大概 1 分钟，晃一晃锅鱼跟着动起来；（煎制 3 分钟左右）

12. 翻面继续煎制；

13. 炒配菜：锅热加油——>藕片、土豆、玉米等，加入一些盐——>炒个三分钟，加入西兰花🥦、芹菜（1 分钟）——>放入烤鱼盘；

14. 烤鱼放入烤鱼盘；

15. 烤鱼料汁：锅热加油——>油热加入：葱姜蒜，葱姜蒜炒香（广告）；

16. 淋浇、蒜末、小米辣、花生米、小香葱；

17. 热油泼（加干辣椒）

## 2. 步骤

1. 鱼从背部切开，贴骨血要擦干净，这样就不会有鱼腥味；

    ::: details

    <img src="./10-烤鱼.assets/image-20250920062617467.png" style="zoom:25%;" />

    :::

2. 在肉厚的地方改刀：

    ::: details

    <img src="./10-烤鱼.assets/image-20250920062755315.png" style="zoom:25%;" />

    :::

3. 准备：姜片、大葱段、花雕酒、生抽、盐，抓匀挤压出葱姜的味道；

4. 把料汁均匀的涂抹在鱼上面，保鲜膜封上，腌制半个小时；

5. 腌制好了之后，在鱼皮表面拍上淀粉；

6. 煎鱼：先用生姜在锅底擦一遍，其次导入油之后，撒一小层盐，防止粘鱼；

7. 油温五层热时，鱼皮朝下；

8. 煎制的时候，多动动其它部位煎制，煎制好鱼皮后翻身煎制；

@tab 4. 小红书

## 1. 食材

| 鱼       | 盐         | 胡椒粉     | 小香葱   | 姜   | 蒜   |
| -------- | ---------- | ---------- | -------- | ---- | ---- |
| **洋葱** | **黄瓜条** | **豆瓣酱** | **蚝油** |      |      |





## 2. 步骤

1. 鲈鱼从背部切开；
2. 洗干净，鱼皮表面改花刀；
3. 撒上盐和胡椒粉、放入葱姜蒜、料酒腌制半个小时；
4. 洋葱铺底，鲈鱼放上面，表面抹一些油；
5. 烤箱提前预热：200 度烤 30 分钟；
6. 准备：蒜末；
7. 锅热加油，下入：蒜末煸香——>加入：豆瓣酱、蚝油、生抽、盐、白糖、1 瓶啤酒；
8. 准备喜欢的配菜铺底：洋葱、莴笋、豆芽、莲藕、黄瓜条；
9. 放上烤鱼，淋上蒜蓉汤汁，继续放在火上煮开；
10. 最后加上花生米、蒜末、芹菜叶，热油激想（热油泼）；

## 2. 步骤

1. **准备部分：**

    1. 鱼从背部打开，鱼改刀不要切开两边，开中间就行；
    2. 用盐擦拭鱼全身，并用水清洗；
    3. 腌制鱼：葱、姜、水、加盐、花雕酒、胡椒、、简单腌制即可（鱼新鲜现杀）（30 分钟）
    4. 我忍不住清洗了一下；
    5. 鱼表面抹点生粉；

2. **准备配菜：**

    1. 土豆片、洋葱切块、莲藕切片、小香葱碎、小米辣、黄瓜、木耳、玉米、豆芽、芹菜等；

3. **煎炸鱼：**

    1. tip：先用生姜在锅底擦一遍，其次倒入油之后，撒一小层盐，防止粘鱼；

    2. 锅中少量油——>火：调整到中火——>鱼的背部先煎一下；

    3. 不要动这条鱼，看中间焦化差不多了，可以动整个锅把鱼的每个部位煎制；（小火慢煎 2 分钟）

        > 其实鱼是不会粘锅的，粘锅是因为油温下降，鱼出水了。导致鱼皮粘在上面；

4. **炒配菜：**

    1. 锅热加油——>藕片、土豆、玉米等，加入一些盐——>炒个三分钟；

    2. 加入西兰花🥦、芹菜（1 分钟）

    3. 一些白胡椒、鸡粉——>炒完之后放入烤鱼盘；

        > 另一种方法就是放入烤鱼料中直接煮，煮一会之后倒入烤鱼盘；

5. **准备料汁：**

    1. **不辣版：**
        1. 蒜末煸香——>加入：豆瓣酱、蚝油、生抽、盐、白糖、1 瓶啤酒（水）；
    2. **辣版：**
        1. 锅热加入菜籽油——>下入：蒜片、小米辣、豆瓣酱、辣椒面、火锅底料、2 瓶啤酒（8+1）；

6. **准备出餐：**

    1. 把喜欢的配菜铺底，和放在鱼的底部；（洋葱块）
    2. 烤鱼放到烤鱼盘上；
    3. 加入配菜；
    4. 淋上蒜蓉汤汁，继续放在火上煮开；
    5. 最后加上花生米、蒜末、芹菜叶，热油激香（热油泼）；
